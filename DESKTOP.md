# Grand CSV: установка на другой компьютер

Версия 0.5.0 — самостоятельное приложение с окном загрузки файлов, предпросмотром и сохранением CSV. Python, Node.js, ГРАНД-Смета, браузерный сервер, интернет и аккаунт ChatGPT для работы установленного приложения не требуются. Интернет нужен только для скачивания установщика.

**Установка не добавляет полный разбор GSDX.** Исходные наименования, единицы, цены и расходы ресурсов из бинарного блока GSH по-прежнему не извлекаются. Для GSDX доступны коды, поисковые слова и доступные технические тексты. Старый двоичный GSF и Data.xml.crypt не поддерживаются. Открытые GSFX/XML читаются как в веб-конвертере.

## Что скачать

Откройте [релиз v0.5.0](https://github.com/edpik/grand-agent-parser/releases/tag/v0.5.0) и выберите один файл:

| Компьютер | Файл |
|---|---|
| Windows 10/11, Intel или AMD 64-bit | `Grand-CSV-0.5.0-win-x64.exe` |
| Mac с M1, M2, M3, M4 и новее | `Grand-CSV-0.5.0-mac-arm64.dmg` |

`grand_agent_parser_0.5.0.zip` — исходники и готовая браузерная сборка. Для обычной установки выбирайте EXE или DMG из таблицы.

## Windows

1. Скачайте EXE, запустите его и выберите папку установки.
2. Установка выполняется для текущего пользователя; права администратора не требуются при выборе доступной пользователю папки.
3. Запустите **Grand CSV** через ярлык на рабочем столе или меню «Пуск».
4. Выберите/перетащите файлы, нажмите «Преобразовать», выберите состав данных и «Скачать CSV».
5. Укажите папку сохранения в обычном окне Windows.

Удаление: **Параметры → Приложения → Grand CSV → Удалить**. Для переноса на другой компьютер достаточно передать установщик и установить его там.

## macOS, в том числе MacBook Air M4

1. Для M4 скачайте файл **mac-arm64.dmg**.
2. Откройте DMG и перетащите **Grand CSV** в **Applications / Программы**.
3. Запустите Grand CSV из папки «Программы».
4. Добавьте файлы и сохраните CSV через стандартное окно macOS.

Сборка имеет локальную ad-hoc подпись, без Developer ID и нотариализации Apple. Поэтому macOS может заблокировать первый запуск загруженного приложения: после попытки запуска откройте **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть** и подтвердите запуск именно Grand CSV. Наличие и текст кнопки зависят от версии macOS и политики компьютера. На управляемом рабочем компьютере запуск может потребовать разрешения администратора.

## Локальная обработка

Приложение содержит интерфейс, парсер, Worker, пример и библиотеки внутри установщика. Загрузка файлов, распаковка, поиск и создание CSV выполняются на компьютере. Нет автоматической проверки обновлений или отправки файлов серверу. Ссылки GitHub и инструкции издателя открываются в системном браузере только после нажатия.

CSV сохраняется в выбранное пользователем место. Загруженные файлы и результаты не восстанавливаются после закрытия приложения. Лимиты и точность значений совпадают с [веб-конвертером](WEB.md).

Неподписанный Windows-установщик может вызвать предупреждение SmartScreen об неизвестном издателе. Корпоративная политика может запретить такую установку. Публичные сертификаты подписи Windows/Apple в проекте не настроены; подпись доверенным издателем в этот релиз не входит.

## Сборка из исходников

Node.js 22.12+; Python 3.10+ нужен только для отдельного CLI. В терминале из корня репозитория:

```bash
npm ci --prefix web
npm run build --prefix web
npm ci --prefix desktop
npm run install:runtime --prefix desktop
npm test --prefix desktop
npm start --prefix desktop
```

Собрать установщик для текущей системы:

```bash
npm run dist --prefix desktop
```

Файлы появятся в `desktop/release`. macOS-пакеты собираются на Mac, Windows EXE — на Windows. В GitHub Actions используется матрица отдельных систем и архитектур.

## Проверки релиза

Сценарий `desktop/tests/smoke.mjs` запускает настоящее окно Electron, читает встроенный GSFX через настоящий Web Worker, сохраняет CSV с BOM, загружает синтетический GSDX и проверяет явное сообщение о неполном чтении. Также проверяются защищённый контекст, отсутствие Node.js в окне и запрет внешних HTTP-запросов.

В релизной матрице проверяется приложение из Windows-установщика, скопированное приложение из DMG без подключения к серверу. Отчёты `qa-*.json` входят в релиз. Сборки публикуются только после успешных проверок всей матрицы; контрольные суммы — в `SHA256SUMS.txt`.
