# История изменений

## v0.5.0

- Самостоятельное приложение Grand CSV на Electron для Windows x64 и macOS arm64 (M1–M4 и новее).
- Полные установщики EXE/DMG включают интерфейс, парсер, Worker и библиотеки. Установленная версия работает без Python, Node.js, интернета, сервера и аккаунта ChatGPT.
- Стандартное окно сохранения CSV, меню программы, локальная обработка и явное описание ограничений форматов.
- Настоящий сценарий Electron: GSFX, GSDX, Worker, сохранение CSV с BOM; приложение из каждого установщика проверяется на целевой ОС до публикации.
- Публикация всех файлов и SHA256SUMS только после успешной сборки всей матрицы.
- Длинные тексты ограничены по высоте только в предпросмотре; CSV сохраняет полный результат.

Полный экспорт GSDX с исходными наименованиями, единицами, ценами и расходами ресурсов не добавлен. Windows EXE без сертификата доверенного издателя; macOS — ad-hoc подпись без нотариализации Apple.

## v0.4.0

- Исправлен бесполезный экспорт GSDX, автоматически выдававший строки каталога за основной результат. Теперь по умолчанию открываются записи из индекса кодов; при отсутствии записей показывается предупреждение.
- CodeIndex связан с границами DocRows. При наличии FtsWords/Fts2 читаются упорядоченные поисковые слова, без восстановления исходного оформления.
- На nb111125 вместо одной строки каталога получены 620 записей и 620 поисковых текстов (160 799 слов); результаты JS/Python совпадают и проверены по обратному индексу.
- Python сохраняет base_index_records.jsonl и индексирует их для поиска.
- Интерфейс явно сообщает о частичной выгрузке. Исходные названия, единицы, цены и расходы ресурсов не декодированы; отсутствующие данные не выдаются за прочитанные.
- 36 веб-тестов и 17 Python-тестов. Визуальная проверка браузера недоступна; сценарий загрузки/выбора режима/скачивания проверен в DOM с настоящим конвертером.

## v0.3.0

- Загрузка GSDX SDB5 в браузере: каталог сборников, технические тексты по страницам, XML каталога/зон/оглавлений и реестр блоков.
- Отдельные режимы CSV и автоматический выбор каталога при загрузке только GSDX.
- SHA-256 источника, ID документа, папки, блок, страница и смещения; неизвестные блоки отмечены uninterpreted.
- Лимиты 256 МиБ на файл / 512 МиБ суммарно; ограниченная распаковка и обработка в Web Worker.
- Проверки SDB5, DEFLATE, HTML2 и вложений; 32 веб-теста и 13 Python-тестов.
- Результат сверяется на реальных базах с Python-парсером, включая тексты всех страниц.

Числовые расценки и ресурсы GSDX пока не декодируются. Экспорт частичный, для каталога и поиска по техническим текстам; не для расчёта сметы. Двоичный GSF по-прежнему требует XML-экспорта. Визуальная браузерная проверка недоступна; выполнены проверки конвертера, DOM-сценария и сборки.

## v0.2.0

- Веб-интерфейс: загрузка до 10 файлов, предпросмотр, поиск и скачивание CSV.
- Чтение открытого Data.xml из GSFX и XML-содержимого в GSF/XML.
- Два состава CSV: позиции локальной сметы и все XML-поля документа.
- UTF-8 с BOM для Excel/Numbers, разделители «;», «,» и табуляция.
- Исходные десятичные строки, формулы, XML-пути и SHA-256 файла.
- Обработка на устройстве в Web Worker, без отправки загруженных файлов на сервер.
- Проверка CRC и ограничений ZIP, явные сообщения для двоичного GSF и защищённых файлов.
- 23 теста веб-конвертера, включая интеграционный тест DOM с загрузкой, фильтром, скачиванием и обработкой ошибки; 13 тестов Python-парсера.

Прямое чтение старого двоичного GSF не реализовано. Для него требуется XML-экспорт через ГРАНД-Смету или Repair. Браузерная визуальная проверка в рабочей среде недоступна; выполнены проверки конвертера, DOM-сценария и статической сборки.

## v0.1.0

- Разбор каталога GSDX SDB5 и доступных многостраничных HTML-статей.
- JSONL и SQLite FTS5 с SHA-256 источника, номером страницы и границами фрагмента.
- Извлечение позиций локальных смет из открытого `Data.xml` в GSFX.
- Импорт открытого XML ФСНБ: нормы, состав операций, ресурсы и исходные десятичные значения.
- Явная обработка `Data.xml.crypt` и неинтерпретированных бинарных блоков.
- Проверки границ, размера распаковки, XML, путей ZIP и отсутствия перезаписи результатов.
- 13 автоматических тестов; инструкция запуска на macOS.

Ограничения: числовая часть GSDX не реализована. Обычный GSFX проверен на синтетическом образце по официальной XSD, а не на реальной пользовательской смете. Применимость нормативов и правильность сметного расчёта требуют отдельной проверки.
