Самостоятельное приложение **Grand CSV**: загрузка файлов, предпросмотр и сохранение CSV, без Python/Node.js/интернета после установки.

- **Windows 10/11 Intel/AMD:** `Grand-CSV-0.5.0-win-x64.exe` — установщик для текущего пользователя.
- **Mac M1–M4 и новее:** `Grand-CSV-0.5.0-mac-arm64.dmg` — открыть DMG, перенести Grand CSV в «Программы».

[Подробная инструкция установки](https://github.com/edpik/grand-agent-parser/blob/v0.5.0/DESKTOP.md).

**Полный разбор GSDX с исходными названиями, единицами, ценами и расходами ресурсов не реализован.** Этот релиз упаковывает существующий парсер. Для GSDX доступны коды, поисковые слова и доступные технические тексты. Открытые GSFX/XML поддерживаются; двоичный GSF и Data.xml.crypt не поддерживаются.

Windows-сборка без подписи доверенного издателя; macOS — с ad-hoc подписью без нотариализации Apple. SmartScreen/Gatekeeper могут показать предупреждение при первом запуске; действия описаны в инструкции. Корпоративная политика может запретить установку.

Установщики собираются на отдельных runner Windows/macOS. Перед публикацией проверяется запуск приложения из каждого пакета, настоящий Worker и сохранение CSV; отчёты — `qa-*.json`. Проверить скачанные файлы можно по `SHA256SUMS.txt`.

`grand_agent_parser_0.5.0.zip` содержит исходники Python/веб/desktop и готовую браузерную сборку `web/dist`; для обычной установки используйте файл вашей ОС выше.
