СОВМЕСТИМОСТЬ

Какой файл можно преобразовать?

.gsdxНормативная база SDB5Частично

В CSV доступны коды записей базы, слова из поискового индекса, каталог сборников, технические тексты по страницам, XML-структура и реестр блоков. Поисковый индекс не сохраняет оригинальный регистр, пунктуацию и все слова; он не заменяет исходную карточку. Расценки и числовые ресурсы из бинарных блоков не декодируются. Тексты можно использовать для поиска и ИИ-агента; расчёт сметы по ним не выполняется.

.gsfxСмета с открытым Data.xmlПоддерживается

Конвертер читает позиции локальной сметы и сохраняет исходные значения. Если внутри находится Data.xml.crypt или архив защищён паролем, экспортируйте документ в обычный XML из ГРАНД-Сметы.

.gsfДокумент старого форматаЗависит от содержимого

Файл с читаемым XML или ZIP с Data.xml можно обработать. Старый двоичный GSF сначала нужно преобразовать в XML через ГРАНД-Смету или утилиту Repair на Windows. Переименование расширения не меняет формат. Инструкция издателя ↗

.xmlXML-экспорт документаПоддерживается

Для локальной сметы доступна выгрузка позиций. Другие структуры можно сохранить в режиме «Все XML-поля». Сохранённые формулы не вычисляются, отсутствующие значения не заменяются нулями. Для кодов с ведущими нулями при импорте CSV в Excel выберите тип столбца «Текст».
